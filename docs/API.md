# API status for STALZONE features

В репозитории STALZONE нет описанного публичного API аукциона или игрового backend API. В `loader/config.json` присутствует только URL загрузки DLL (`dll_url`), а endpoint для аукциона отсутствует.

## Откуда брать API легально

1. Документация разработчика игры или официальный SDK.
2. Официальный серверный API, если он опубликован владельцем игры.
3. Партнёрский/моддинг-SDK с явным разрешением на использование.
4. Собственный тестовый backend для разработки интерфейса.

Не следует извлекать закрытые endpoint'ы, токены, сетевые ключи или игровые структуры из памяти клиента. Без документированного API нельзя достоверно реализовать `Scanner` или `QuickAuction`, поэтому эти исходники исключены из активной CMake-сборки до появления разрешённого контракта.

## Минимальный контракт для будущего backend

```text
GET /auction/listings?limit=N
Authorization: <documented application credential>

Listing:
  id: string
  title: string
  price: number
  currency: string
  rarity: integer
  updated_at: timestamp
```

Это только интерфейсный пример, не описание реального API STALZONE или какой-либо игры. Реализацию можно добавлять после получения официальной документации и условий доступа.
